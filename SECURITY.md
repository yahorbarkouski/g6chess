# Security policy

Please report vulnerabilities privately to `admin@g6chess.com`. Include the
affected commit, reproduction steps, impact, and any proposed mitigation.

Do not include live credentials or personal game data. We will acknowledge a
report within seven days and coordinate disclosure after a fix is available.

Only the latest `main` branch is supported. Deployment is a separate,
manual action through a protected GitHub environment; merging or publishing
source does not deploy the backend.
